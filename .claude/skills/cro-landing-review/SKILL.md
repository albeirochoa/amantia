# Skill — CRO Landing Review

## Objetivo
Revisar una landing y proponer mejoras de conversión.

## Evaluar
- claridad inicial,
- relevancia,
- prueba,
- objeciones,
- CTA,
- información comercial,
- mobile,
- fricción.

## Formato
Observación → Hipótesis → Cambio → Métrica.
