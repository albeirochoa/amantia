# Skill — Pre-deploy SEO QA

## Antes de publicar

Verificar:
- URL aprobada,
- intención correcta,
- title único,
- meta description,
- H1 único,
- canonical,
- schema,
- breadcrumbs,
- enlaces,
- imágenes,
- alt,
- mobile,
- performance,
- tracking,
- CTA,
- datos reales,
- noindex donde corresponda.
