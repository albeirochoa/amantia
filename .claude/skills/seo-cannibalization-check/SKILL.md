# Skill — SEO Cannibalization Check

## Objetivo
Evitar que dos páginas compitan por la misma intención.

## Comparar
- query objetivo,
- intención,
- SERP,
- H1,
- contenido,
- protagonista,
- CTA,
- etapa de funnel.

## Resultado
- `NO_CONFLICT`
- `MERGE`
- `DIFFERENT_INTENT`
- `NEEDS_RESEARCH`
