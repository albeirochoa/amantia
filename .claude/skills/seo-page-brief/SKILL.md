# Skill — SEO Page Brief

## Objetivo
Crear un brief de página antes de redactar o programar.

## Debe incluir
- URL,
- intención,
- funnel,
- keyword principal,
- secundarias,
- protagonista,
- usuario,
- objetivo,
- H1,
- secciones,
- CTA,
- FAQs,
- enlaces internos,
- datos pendientes,
- riesgos de canibalización.

No redactar contenido final si hay datos críticos en `TODO`.
