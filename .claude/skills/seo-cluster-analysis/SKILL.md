# Skill — SEO Cluster Analysis

## Objetivo
Determinar si una oportunidad pertenece a un clúster existente o requiere una nueva URL.

## Proceso
1. Identificar intención.
2. Identificar funnel.
3. Comparar contra URL map.
4. Revisar protagonista.
5. Evaluar solapamiento.
6. Recomendar:
   - consolidar,
   - ampliar,
   - crear,
   - descartar.

## Output
- keyword/tema,
- intención,
- clúster,
- URL recomendada,
- funnel,
- protagonista,
- decisión,
- justificación.
