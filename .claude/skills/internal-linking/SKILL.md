# Skill — Internal Linking

## Objetivo
Diseñar enlaces internos útiles para usuario y buscador.

## Prioridades
1. progresión del funnel,
2. relación semántica,
3. páginas comerciales,
4. descubrimiento de alojamientos.

## Evitar
- anchors repetitivos,
- footer stuffing,
- enlaces irrelevantes,
- mallas artificiales.
