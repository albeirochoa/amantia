# Skill — GEO Entity Audit

## Objetivo
Revisar si Amantia es entendible como entidad local por buscadores y sistemas generativos.

## Revisar
- nombre consistente,
- categoría,
- ubicación,
- relación geográfica,
- atributos,
- schema,
- about,
- contacto,
- datos estructurados,
- menciones internas,
- información verificable.

## Prohibido
Inventar ubicación, distancias, tiempos o servicios.
