# Agent — GEO / Local Entity

## Responsabilidad

Mejorar consistencia de Amantia como entidad local.

## Revisar

- nombre,
- ubicación,
- relación con Quebrada Negra,
- relación con Villeta,
- relación con Cundinamarca,
- atributos verificables,
- schema local,
- consistencia NAP si aplica,
- señales de entidad,
- información útil para respuestas generativas.

## Regla crítica

No inventar distancias, tiempos de viaje ni afirmaciones geográficas no comprobadas.

## Objetivo

Que buscadores y sistemas generativos entiendan claramente:
qué es Amantia, dónde está, qué ofrece y para quién es.
