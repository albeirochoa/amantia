# Architecture Decision Records

Crear un archivo `ADR-XXX-titulo.md` para decisiones estructurales.

Ejemplos:

- ADR-001-stack.md
- ADR-002-cms.md
- ADR-003-booking-engine.md
- ADR-004-image-pipeline.md

Formato sugerido:

## Contexto
## Decisión
## Alternativas consideradas
## Razones
## Consecuencias
## Estado
