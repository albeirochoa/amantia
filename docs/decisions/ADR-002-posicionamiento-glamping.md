# ADR-002 — Posicionamiento: glamping como categoría, refugio como voz

## Contexto

El Agent Pack organiza el SEO alrededor de "glamping" (`docs/seo/url-map.md`). La identidad de marca original prohibía "glamping de lujo" y usaba "refugio". La auditoría del 2026-10-06 lo marcó como conflicto.

## Decisión

Aprobado por el dueño el 2026-10-06: **"glamping" sí va.** `CONFIRMED`

- "Glamping" es la **categoría**: URLs, titles, meta descriptions, H1 de landings SEO, schema y la descripción en redes.
- "Refugio" sigue siendo la **voz** del copy editorial y emocional.
- Se mantiene la prohibición de "glamping de lujo", "hotel boutique" y los clichés de `AGENTS.md` §6.

## Alternativas consideradas

- Solo "refugio": no captura la demanda de búsqueda, que está en "glamping".
- Solo "glamping": diluye la voz de marca contenida.

## Consecuencias

- Las URLs P0 de `docs/seo/url-map.md` quedan habilitadas para validación por `amantia-seo-strategist` (siguen siendo hipótesis hasta revisar intención/SERP).
- El title y la description de `/` pueden incorporar "glamping" en una revisión SEO futura.

## Estado

Aceptada.
